# 🔧 Oficina Inteligente

Sistema inteligente para gestão de manutenção de ferramentas.

## 🎯 Objetivo

Desenvolver uma solução para auxiliar oficinas de manutenção no controle de ferramentas, ordens de serviço, diagnósticos, produtividade e histórico de reparos.

## 🚀 Funcionalidades

- Cadastro de ferramentas
- Ordens de serviço
- Registro de diagnóstico
- Controle de manutenção
- Histórico de reparos
- Controle de tempo de serviço
- Indicadores de produtividade
- Assistente de IA para apoio ao diagnóstico

## 🤖 Inteligência Artificial

O projeto terá um assistente de IA para auxiliar o profissional de manutenção na organização do diagnóstico e na sugestão de verificações técnicas.

A IA será utilizada como ferramenta de apoio, sem substituir a avaliação do profissional.
